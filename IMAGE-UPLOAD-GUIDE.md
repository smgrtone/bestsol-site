# Image upload guide

Upload actual photographs directly into `assets/img/`, using the exact filenames below. Each image slot starts with a local SVG illustration with its subject, dimensions, crop advice and filename embedded INSIDE the SVG image itself. There are no HTML instruction panels, caption fields or external image hosts. The image switches to your photograph only when that file loads successfully; a missing or invalid image leaves the local placeholder visible. If a replacement subsequently fails, the placeholder is restored.

The dimensions below are recommended source-image dimensions, not CSS display dimensions. Keep subjects central and allow space for responsive cropping. Placeholders use object-fit: contain to retain all embedded text; uploaded photographs use object-fit: cover, except the logo and diagram/equipment slots marked contain.

Upload to the same branch being published. Do not rename or delete the placeholder SVGs. Match spelling, letter case and image extension exactly. For replacement photographs, data-photo-alt in the page HTML supplies the intended alt text automatically; revise it to accurately describe the photograph if the subject differs. Update both the normal alt and data-photo-alt if needed. Do not publish unrelated laboratory photographs as your own facility. Confirm facility identity, access and status.

All six headers use a neutral circular placeholder with no B. Upload assets/img/header-icon.png (500 × 500 px square PNG, preferably transparent) to replace it. Display size: 42 × 42 px, clipped to a circle. logo.png remains reserved and does not control the header.
